# motor-animado
Da frase ao vídeo vertical animado, numa página que abre no seu navegador.  Você escreve a ideia em uma frase. Um agente de IA pesquisa, confere os fatos, escreve o roteiro e sugere o estilo. Você escolhe a aparência e personaliza numa prévia. O painel grava a voz, monta as cenas, renderiza, mixa e confere o resultado.
